# Шагомер для Windows 10 Mobile

UWP-приложение (C#, XAML) для подсчёта шагов на телефонах с Windows 10 Mobile.
Проект для **Visual Studio 2017**.

## Что умеет сейчас

- Страница на каждый день: **свайп вправо — предыдущий день** (до года назад),
  кнопка «сегодня» возвращает к текущему дню. Если записей за день нет — «Нет данных».
- Шаги и ккал за день, прогресс к цели, расстояние.
- Текст поощрения/мотивации под шагами и ккал (зависит от процента нормы), сравнение ккал «≈ N яблок».
- Количество тренировок (непрерывная активность от 10 минут, перерывы до 2 минут) и время активности.
- Диаграмма активности по часам: синие столбцы — шаги, оранжевые — ккал.
- Экран «статистика»: неделя / месяц / год с листанием на прошлые периоды — средние в день
  (шаги, ккал, км, время активности), диаграмма по дням (для года — по месяцам), итоги периода,
  дней с выполненной нормой, лучший день.
- Праздник с конфетти и сообщением «Норма выполнена! Так держать!» при выполнении нормы (один раз в день).
- Настройки: дневная цель, длина шага, вес.
- Переключатель «Работать при выключенном экране» (`Services/BackgroundKeeper.cs`):
  продлённое выполнение (ExtendedExecutionSession, причина LocationTracking), чтобы
  подсчёт по акселерометру не останавливался под экраном блокировки. Использует
  местоположение по сетям (capability `location`). Система может отозвать разрешение
  при нехватке памяти или в режиме экономии заряда — тогда приложение запросит его снова при открытии.
- Данные хранятся в SQLite (`LocalFolder\steps.db`, библиотека sqlite-net-pcl).
- Источники шагов (GPS не используется):
  1. **Встроенный шагомер** (`Windows.Devices.Sensors.Pedometer`, например Lumia 950/950 XL, 650, 550).
     Шаги считает система, в том числе когда приложение закрыто; при запуске приложение
     забирает системную историю (до 30 дней) в свою базу.
  2. **Акселерометр** — запасной вариант для телефонов без шагомера. Считает,
     только пока приложение открыто на экране (`Services/StepDetector.cs`).

## Как устроены данные

- `Segments` — отрезки активности: время окончания, активная длительность, шаги, ходьба/бег, день и час.
- `Days` — итоги дня (шаги, бег, время активности, тренировки), пересчитываются из отрезков.
- Ккал и расстояние не хранятся, а считаются по текущим настройкам (вес, длина шага),
  поэтому после изменения настроек пересчитывается и вся история.

## Сборка и запуск

1. Откройте `StepCounter.sln`.
2. При первой сборке NuGet восстановит `Microsoft.NETCore.UniversalWindowsPlatform` 5.4.7 и
   `sqlite-net-pcl` 1.5.231. Обновлять их до 6.x / 1.6+ нельзя: новые версии требуют
   .NET Standard 2.0 (минимум Windows 16299), а такой сборки Windows 10 Mobile нет.
3. Тестовый сертификат в репозиторий не добавлен. Если VS попросит его создать:
   откройте `Package.appxmanifest` → вкладка «Упаковка» → «Выбрать сертификат…» →
   «Создать тестовый сертификат».
4. Платформа **ARM**, цель **Device** (телефон подключён по USB и в режиме разработчика).
   Для эмулятора — платформа **x86**.

При первом запуске на телефоне может понадобиться разрешить доступ:
«Параметры → Конфиденциальность → Движение». На главном экране в этом случае появится ссылка.

## Структура

```
StepCounter/
  App.xaml(.cs)                 запуск, цвета, кнопка «Назад», приостановка/возобновление
  Package.appxmanifest          манифест (capability "activity")
  Data/                         SQLite: отрезки активности, итоги дней
  Services/
    IStepSource.cs              общий интерфейс источника шагов
    HardwarePedometerSource.cs  встроенный шагомер + системная история
    AccelerometerStepSource.cs  подсчёт по акселерометру
    StepDetector.cs             алгоритм распознавания шагов
    ActivityMath.cs             ккал, расстояние, тренировки
    Motivation.cs               тексты поощрения, склонения
    AppSettings.cs              настройки
  ViewModels/                   MainViewModel, DayViewModel (страница дня), StatisticsViewModel
  Controls/                     столбчатая диаграмма, праздничный экран
  Views/                        MainPage, StatisticsPage, SettingsPage
  Assets/                       иконки-заглушки
```
